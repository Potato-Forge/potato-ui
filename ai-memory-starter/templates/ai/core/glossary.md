## Agent Memory Terms

- **Entry**: A thin Agent-specific key such as `AGENTS.md` or `CLAUDE.md`.
- **Vendor**: Generic `.ai` protocol and behavior rules.
- **Core**: Stable project facts and durable decisions.
- **State**: Current project status and handoff.
- **Logs**: Sanitized project event ledger.
- **Private**: Local-only sensitive or personal context.
