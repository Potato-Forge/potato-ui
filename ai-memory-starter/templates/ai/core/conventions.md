## Git And Memory

- Track `.ai/core/` for stable project facts.
- Track `.ai/state/` for current status when useful to collaborators.
- Track `.ai/logs/` only if entries are sanitized.
- Ignore `.ai/private/`, `.ai/tmp/`, and `.ai/archive/raw/`.
